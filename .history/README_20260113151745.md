# THE SOHO - Moderne Kontaktseite

Eine moderne, elegante Kontaktseite für THE SOHO Friseur in Krefeld.

## Features

✨ **Modernes Design**
- Elegante Farbpalette mit Gold-Akzenten
- Hochwertige Typografie (Cormorant Garamond + Montserrat)
- Smooth Animationen und Übergänge
- Responsive Design für alle Geräte

🎨 **Stilelemente**
- Hero Section mit Gradient-Hintergrund
- Animierte Kontakt-Karten
- Interaktive Google Maps Integration
- Social Media Buttons mit Hover-Effekten
- Eleganter Footer

📱 **Responsive**
- Desktop-optimiert (1200px+)
- Tablet-freundlich (768px - 1199px)
- Mobile-optimiert (<768px)

## Verwendete Technologien

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript
- Google Fonts (Cormorant Garamond, Montserrat)
- Google Maps Embed

## Installation

1. Dateien auf Webserver hochladen
2. In Browser öffnen: `index.html`
3. Fertig! 🎉

## Anpassungen

### Farben ändern
Bearbeite die CSS-Variablen in `styles.css`:
```css
:root {
    --primary-color: #1a1a1a;
    --secondary-color: #d4af37;
    --accent-color: #c9a961;
}
```

### Google Maps
Ersetze die Map-URL in `index.html` mit deiner eigenen Adresse.

### Öffnungszeiten
Passe die Zeiten im HTML an (Zeile ca. 150-160).
